# Квиз SRG по новостройкам

Готовый квиз находится в `SRG_quiz.html`. Все стили, скрипты, логотип и иллюстрация встроены в файл.

Для скачивания новой версии по брендбуку используйте `SRG_quiz_brandbook.zip` (актуальная версия также находится в `SRG_quiz.zip`): распакуйте архив и откройте `SRG_quiz.html` в Safari или Chrome.

Квиз включает заставку, четыре вопроса по схеме референса, мобильную версию, чек-лист покупателя и правовые документы по ссылкам. Ветка бюджета до 4 млн ₽ ведёт к чек-листу без обязательной заявки.

Приём заявок требует подключения обработчика: в теге формы укажите его URL в атрибуте `data-endpoint`. Обработчик должен принять JSON через POST и вернуть HTTP 2xx с JSON `{"ok":true}` или `{"success":true}` после приёма заявки. Пока адрес пуст, сайт сообщает, что онлайн-отправка недоступна. Персональные данные не сохраняются в localStorage.

Сайт не развёрнут и не опубликован: в этой ветке сохранены только файлы для скачивания.

## Оформление по брендбуку SRG

В версии по брендбуку использованы предоставленные материалы SRG: SVG-логотип, основной голубой #00B2E0, кобальт #0143A2 и синий #0062D8, белый и графитовый #1A1A1A. Заголовки — Gilroy Bold; основной текст — Century Gothic Regular/Bold. Применены фирменный сетчатый градиент и заливные голубые/белые иконки из банка.

Шрифты, логотип, иконки и оптимизированный градиент встроены в HTML; внешних загрузок для отображения квиза не требуется. Оформление применено к заставке, вопросам, форме контактов, правовым документам, сообщениям и скачиваемому чек-листу. Архивы брендбука в репозиторий не добавлялись.

Проверены обе ветки квиза, выбор нескольких ответов, восстановление ответов при возврате, валидация телефона, ссылки на документы, скачивание чек-листа и ошибки/успех отправки с тестовым обработчиком. Проверены мобильные и настольные ширины 320–1440 px, загрузка трёх начертаний фирменных шрифтов и отсутствие внешних ресурсов.

Предпросмотр: `SRG_preview_brandbook.png`.
